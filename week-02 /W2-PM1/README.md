# W2-PM1 – Footprinting & Reconnaissance

## Objective
To perform footprinting and reconnaissance on `networkwalks.com` using six built-in Kali Linux tools to gather publicly available information about the target.

## Tools and Tasks

| No. | Tool | Purpose |
|---|---|---|
| 1 | whois | Domain registration details |
| 2 | whatweb | Website technology fingerprinting |
| 3 | nslookup | Domain-to-IP resolution |
| 4 | curl | HTTP response header analysis |
| 5 | wafw00f | Web Application Firewall detection |
| 6 | dnsrecon | DNS record enumeration |

## Practical Activities

1. Retrieved domain registration information using `whois`.
2. Identified website technologies using `whatweb`.
3. Resolved the domain name using `nslookup`.
4. Inspected HTTP response headers using `curl -I`.
5. Checked for Web Application Firewall protection using `wafw00f`.
6. Enumerated DNS records using `dnsrecon`.

The findings from each task are documented using actual command outputs and screenshots.
